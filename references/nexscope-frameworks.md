## 一、跨境市场评分（8 维加权）

给目标市场打分排序（1-10 分 × 权重），选前 2-3 个市场：

| 维度 | 权重 | 衡量什么 |
|---|---|---|
| 市场规模 | 20% | 电商总营收 + 本品类需求 |
| 电商渗透率 | 10% | 线上占零售比，越高买家越成熟 |
| 竞争强度 | 15% | 成熟玩家数量、差异化难度 |
| 监管复杂度 | 15% | 税务登记、产品合规、进口限制 |
| 物流基建 | 15% | 履约选项、时效、可靠性 |
| 支付生态 | 10% | 本地支付可得性、欺诈率 |
| 文化距离 | 10% | 语言壁垒、消费行为差异 |
| IP 保护 | 5% | 商标执法、假货风险 |

**复合分 = Σ(维度分×权重)**。用途：跨市场扩展（如越南站跑通后扩泰国/马来）时排序。

## 二、履约模型对比（5 种）

| 模型 | 适合 | 单均成本 | 时效 | 库存风险 | 启动难度 |
|---|---|---|---|---|---|
| 直发 | 测新市场、低量(<50单/月) | 高 | 7-21 天 | 无 | 低 |
| 本地 3PL | 成熟市场、100+单/月 | 中 | 1-5 天 | 中(备货) | 中 |
| 平台仓(FBA/FBT/WFS) | 平台卖家、高量 | 中+费 | 1-3 天 | 中(备货) | 低-中 |
| 代发/POD | 测品、零库存 | 低利润 | 5-15 天 | 无 | 低 |
| 跨境集运 | 多市场、中量 | 中 | 3-10 天 | 低-中 | 中 |

**决策**：<50单/月→直发；50-200→集运/本地3PL；200+→本地3PL/平台仓。**用途**：本 SKILL 的「边境仓→越南本土仓」切换评估套这个框架。

## 三、落地成本计算框架

```text
落地成本 = 产品成本 + 国际运费 + 关税 + 进口税(VAT/GST) + 保险 + 汇损 + 支付手续费 + 退货准备金
```
**用途**：跨境电商常见「国内 68% 毛利 → 跨境跌到 10% 毛利」，用这个逐项拆解找漏损点（本 SKILL 的单位经济模型可吸收此框架）。

## 四、Listing SEO/CRO 双轨框架

- **SEO**：关键词研究(主词/长尾) → 标题(<60字符，主词前置) → 类目+属性映射 → hashtag
- **CRO**：说服性描述(钩子+卖点+USP+包件+适用) → 视觉策略 → 价格定位 → 社会证明
- **9 图框架**：主图(白底1:1) / 场景 / 功能特写 / 尺寸参照 / 包装 / 对比 / 前后 / 信息图 / 社会证明
- **视频要求**：15-30 秒、9:16 竖屏、前 3 秒钩子、明确 CTA

**用途**：上架 QA 的结构化清单（本 SKILL 已做越南语+抠图+PIL 叠字，此框架补「9 图结构」的完整性）。

## 五、广告投放架构

- **3 种广告**：Product Shopping Ads(转化) / Video Shopping Ads(认知) / Live Shopping Ads(活动)
- **出价**：先自动出价收数据 → 再手动；单活动预算保守
- **放大**：赢家 ad set 每次加 20-30% 预算
- **核心指标**：ROAS / CTR / CVR / CPA / Frequency(控疲劳)

**用途**：本 SKILL 投流策略的结构化补充（跑量分级/保本 ROAS 之外，补「广告类型矩阵」）。

## 六、联盟/达人计划结构

- **分层佣金** + 绩效奖励（tier-based）
- **招募链路**：目标达人识别/筛选 → 外联话术 → 申请审批 → onboarding
- **管理**：样品分发 / 内容审批 / 绩效反馈 / 留存激励

**用途**：本 SKILL「达人杠杆工作流」的结构化补充（筛选→触达→寄样→催片→回收→复投 已有，此补「分层佣金 + 绩效激励」设计）。

## 七、内容策略框架

- **内容支柱(content pillars)** + 品牌 voice
- **爆款格式**识别与改编
- **钩子开发**（前 3 秒）
- **内容日历** + 排期
- **UGC** 整合与放大

**用途**：本 SKILL「内容迭代机制」的结构化补充。

## 八、数据分析框架（4 层）

| 层 | 指标 |
|---|---|
| 业务 | 营收趋势 / AOV / 获客留存 / 漏斗 |
| 内容 | 播放 / 互动 / 分享 / 钩子有效性 / hashtag |
| 直播 | GMV/场 / 观众互动 / 主播表现 |
| 达人 | 伙伴绩效 / ROI / 佣金优化 |

**用途**：本 SKILL「运营数据看板(四阶段)」的指标补充（多了「直播/达人」两层）。

## 九、竞品价格地图

- **价格带分布** + 竞品聚类（低价/中价/高价段）
- **价格缺口/机会**（未被覆盖的价格点）
- **价格弹性** + 动态定价行为

**用途**：本 SKILL「竞品分析」的定价锚点补充。

## 十、评论分析框架

- **情感分析**：评分 / 情绪 / 真实性 / 时序趋势
- **痛点/好评模式**：按频率分类（差评=卖点来源）
- **功能需求提取**：未满足需求 → 市场机会

**用途**：本 SKILL「选品打分 + 差评SOP」的结构化补充。

**用途**：本 SKILL「复盘」的诊断框架补充。
