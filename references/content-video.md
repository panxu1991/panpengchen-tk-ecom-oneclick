# 爆款短视频：找、拆、变量复制

目标不是赌单条爆款，而是把「已验证的爆款结构」拆成可复用的模板，再通过**变量复制**批量产出自己的短视频。

## 1 在哪找同类 / 竞品爆款短视频

按官方入口优先，不用第三方爬虫或破解：

- **TikTok Creative Center**（官方）：Top Ads、热门视频、热门标签，按「越南」市场过滤，看同品类近期高播放内容。
- **TikTok Shop 越南站**：竞品商品页的关联视频、达人橱窗、带货榜、热销榜。
- **自有达人库**：`运营跟踪表.xlsx` 的「达人」sheet，按垂类记录高互动账号。
- **搜索词 + hashtag 榜单**：`#dungcubep #doorgianhap #reviewhangcong #nhabep #donhacua #vesinh` 等，看标签下播放量最高的视频。
- **竞品账号主页**：按播放量排序，挑出前 3-5 条稳定出量的视频作为拆解样本。

记录时每条写下来源链接、发布日期、播放/点赞/评论、对应商品，方便回看与去重。

## 2 拆解框架（9 要素）

| 要素 | 看什么 | 记什么 |
|---|---|---|
| 钩子 | 前 3 秒怎么抓住人 | 冲突 / 痛点 / 反差 / 疑问，逐字 |
| 结构 | 起承转合的段落 | 分镜表 |
| 卖点呈现 | 主打哪个卖点、怎么演示 | 1-2 个核心卖点 |
| 画面 | 景别 / 机位 / 转场 | 分镜 |
| 文案 | 口播 + 字幕 | 逐字 |
| BGM / 音效 | 音乐、音效 | 曲名 / 情绪 / 卡点 |
| 节奏 | 每 3 秒一个画面 / 信息点 | 时间轴 |
| 字幕 / 贴纸 | 强调词、价格、箭头、CTA 贴纸 | 位置 |
| CTA | 结尾怎么引导 | 点击 / 关注 / 进橱窗，逐字 |

## 3 拆解模板（逐段）

用一张表把一条爆款视频拆成可复制的零件：

| 时间轴 | 画面 | 口播 / 字幕 | 卖点 | 保留 or 替换 |
|---|---|---|---|---|
| 0-3s | 厨房乱 / 食材发霉 | 「还在为…发愁？」 | 痛点 | 保留结构、换场景词 |
| 3-6s | 产品亮相 | 「用它一次就…」 | 亮相 | 替换产品 |
| 6-10s | 功能实测 | 关键数据 | 卖点 | 保留演示、换数据 |
| 10-13s | before/after | 效果对比 | 效果 | 保留 |
| 13-15s | 结尾 CTA | 「点击链接…」 | 转化 | 保留、换促销话术 |

拆完就能看清：**哪些是「已验证的结构」，哪些是「可替换的变量」。**

## 4 变量复制（variable COPY）

核心原则：**保留已验证的「结构 + 钩子逻辑 + 节奏」，替换「变量」。**

变量矩阵：

| 变量 | 怎么换 | 影响什么 |
|---|---|---|
| 产品 | 同款 → 变体 → 同类目不同款 | 主体 |
| 场景 | 厨房 / 收纳 / 清洁 / 卫生间 | 人群共鸣 |
| 人物 | 出镜人 / 达人 / 手模 / 只拍手 | 信任与亲和 |
| 钩子 | 换痛点、换开场提问、换反差 | 完播率 |
| BGM | 换当下热门曲 / 卡点 | 情绪与节奏 |
| 文案 / 字幕 | 换口语、换强调词、换价格 | 信息传递 |
| 结尾 CTA | 换促销 / 换引导方式 | 转化 |

一次只换 1-2 个变量做 A/B，保留高完播变量，替换低完播变量，而不是每条都全部重写。

## 5 一鱼多吃（一个脚本 → 多条片）

一个验证过的脚本，按「角度 × 达人 × 场景」展开批量产出：

- 5 个角度：使用场景 / 问题解决 / 产品演示 / 对比 / 社会证明。
- N 个达人：给不同达人同一脚本骨架 + 不同口播。
- M 个场景：厨房 / 宿舍 / 收纳 / 清洁，换场景词与画面。

产出 = 1 个脚本 × 5 角度 × 3 达人 × 3 场景 = 可铺开的素材库，而不是每次都从零写。

## 6 批量制作 SOP

1. 脚本：从拆解模板产出 3 条脚本，每条一个核心卖点、一个钩子、一个 CTA。
2. 拍摄 / 混剪：实拍或素材混剪，前 3 秒必须有冲突或痛点，每 3 秒一个画面。
3. 封面：统一模板，大字痛点 / 结果，不用夸大词。
4. 标题 + hashtag：混合大流量词 + 品类词 + 长尾词 + 情绪词，5-8 个。
5. 分发：越南时间晚 7-10 点发布，置顶引导评论。
6. 数据复盘：完播率、点赞、评论、进店、转化、退款，按角度分组。
7. 迭代：保留高完播 / 高转化的变量，替换低效变量，进入下一轮。

## 7 越南语要点与合规红线

- 用自然越南语，不机翻堆词；标题/字幕口语化、具体化。
- 不用医疗、绝对化、虚假折扣、仿品、擦边话术。
- 不编造搜索量 / 排名 / 转化 / 销量。
- 不搬运他人视频；只拆结构、做变量替换，不做逐帧翻拍或盗用素材。
