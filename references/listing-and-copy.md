# 上架与文案（越南站百货）

## 标题（三版本，最终一个上架）

1. 搜索型：核心词 + 属性词 + 场景词 + 长尾词，60-80 字符，核心相关词靠前。
2. 转化型：人群定位 + 核心痛点 + 解决方案，突出 1-2 个最强卖点。
3. 引流型：情绪词 + 人群称呼，适合短视频/直播，但要克制夸张。

规则：
- 用自然越南语，不机械堆关键词。
- 不用医疗、绝对化、虚假折扣、仿品、无法验证的宣称。
- 标题与实际图片、SKU、类目、商品内容一致。
- 最终标题到卖家中心商品优化工具或当前标题工具校验。
- 修改在营标题是不可逆动作，需授权；对比现有搜索/转化数据再改。

## 卖点（5 个 bullet）

公式：痛点 + 方案 + 量化数据/结果。顺序：核心功能 → 场景 → 品质/材质 → 售后/赠品。数字要具体，不用「很多」「很好」。

示例（厨房密封罐）：
```
✅ Nắp silicone kín khí - Đựng thực phẩm khô không ẩm, không mốc
✅ Thủy tinh dày, an toàn - Chịu nhiệt, dễ vệ sinh, không ám mùi
✅ Nhiều kích cỡ - 3 cỡ từ 500ml đến 1.2L, đựng gạo, hạt, gia vị
✅ Thiết kế trong suốt - Nhìn thấy đồ bên trong, xếp gọn tủ bếp
✅ Đổi trả nhanh - Hỗ trợ trong 7 ngày nếu lỗi do sản xuất
```

## 描述

- 短版 100 字内，口语化，像朋友推荐。
- 长版 300-500 字：痛点共鸣 → 展开解决方案 → 促单。

## 关键词与 Hashtag

混合大流量词（#tiktokshop、#reviewhangcong）、品类词（#doorgianhap、#dungcubep）、长尾词（#hopdungthucpham、#keodunha）、情绪/热门词。不要编造搜索量、排名、转化数据，标清 official / observed / estimated / unknown。

## 图片（5 张）

1. 白底主图 1:1，产品居中纯白底。
2. 场景图 3:4，产品在真实使用场景。
3. 细节特写 3:4，材质做工。
4. 卖点信息图 1:1，产品居中，脚本加卖点文字。
5. 尺寸参考图 1:1，产品 + 手作对比。

规则：每张图必须有产品；先出纯底图再加文字；风格统一白底 + 蓝点缀、现代简约；产品清晰、细节可见。提示词强调 `no text, no watermark`，底图生成后由脚本排版加越南语文字。

## 详情页长图（5 张，3:4 竖版）

1. 痛点引入 + 产品亮相。
2. 3 个核心卖点模块。
3. 使用场景（2x2 网格）。
4. 参数/尺寸表。
5. 信任背书 + 包装清单。

所有图统一 3:4、风格一致、文字区留白后期加越南语，不花哨，简洁直接。

## 上架 QA

发布前跑 `scripts/listing_qa.py`，检查：类目、属性、税费敏感价、变体映射、库存、价格、促销、配送、退货、所需文档、宣称合规。发布需授权。
