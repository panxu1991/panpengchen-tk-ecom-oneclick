# TK 电商经验库

## 成功经验

| 经验 | 适用场景 | 复用方式 |
|---|---|---|
| rembg 抠真实产品图做白底 | 主图制作 | 从源链接提取图 → rembg 抠白 → 多体位 |
| PIL+Arial 程序化叠越南语 | 所有带字图 | AI 出无字底图，文字永远 PIL 叠 |
| pdfplumber 提官方佣金 PDF | 费率核验 | CID 字体 PDF 用 pdfplumber，不用朴素正则 |
| openpyxl 建可填写活表 | 复盘表/选品表 | 参数区黄色可编辑 + fullCalcOnLoad |
| FastMoss 游客榜做竞品 | 市场/竞品分析 | 越南站商品榜/达人榜无需登录 |
| 双体系盈亏（商品卡/达人） | 定价 | 佣金/交易费/税/退货/样品全拆解 |
| 多瓶装摊薄边境仓固定费 | 定价 | 3瓶/5瓶装每瓶保本从8.1万降到4.7万 |
| 变量复制批量出短视频脚本 | 内容 | 5角度×5场景×3人物×5香型 |

## 踩坑记录（原因 + 解决方法）

| 踩坑 | 原因 | 解决方法 |
|---|---|---|
| AI 凭空画产品不像 | 没抠真实图 | 源链接真实图 → rembg 抠白 |
| AI 图上越南语音调错 | 生图模型渲染跑偏 | PIL 程序化叠字 |
| 样品成本算低 3 倍 | 用了 (1-P)/P | 改 1/P 全量摊销 |
| 达人出单率中位数算错 | 排序/取值错 | sorted 后 (n/2+n/2+1)/2 |
| kill 用户浏览器登录失效 | 会话绑定实例 | 不 kill，CDP 直连 |
| 复制 profile 带不过国内登录 | 登录绑定浏览器指纹 | 一次性登录+同会话批处理 |
| batch delete+add 同文件失败 | apply_patch 限制 | replace_file 或 os.remove |
| 国内平台(淘宝/1688/京东)反爬 | 扫码+滑块+会话过期 | FastMoss 优先；评论图用户导出或紫鸟 |
| 详情图缺产品(2x2格子) | AI 漏画 | 提示词强制 product in EVERY quadrant |
| 多口径并存(达人出单率/汇率/佣金) | 中途改值未全局同步 | 交付前 rg 全局核对，统一一个值+标注样本量 |
| xlsx B列公式错位+循环引用+静态死值 | 复制旧表残留错列 | 生成后 openpyxl dump 全表核对，删冗余列 |
| 敏感度公式文本截断+锚点漂移 | 锚点引用不存在参数 | 敏感度锚点必须对齐参数区，活公式非文本 |
| Excel 非法"×"符号 | 手写公式用中文乘号 | 一律用 *，不用 × |
| 旧结论未退役(1.41%/ROI 70.82) | 旧表未标注作废 | 淘汰旧值标"已退役"，正解指向活模型 |
| 字幕语境错配(Ngon-bổ-rẻ食品词) | 通用模板未按品类适配 | 内容词匹配品类语境，香薰用"Thơm lâu" |
| 功能宣称无依据(吸潮除霉) | 硬堆卖点超出实证 | 弱化为可验证宣称"除味/留香" |
| 交付表格被简化成单sheet | 重写时图省事只做1个sheet | 交付表格必须保留完整多sheet聚合(边境仓4sheet/跟踪6sheet/数据6sheet/看板7sheet) |
| 打法分析漏时间维度 | 只写头腰尾静态表 | 打法必含开店/上架/跑多久/总销量/何时出单/近180天销量环比，游客态拿不到就留白+备注登录动作 |
| 竞品分析漏规格 | 只抄商品名和售价 | 竞品必含规格(克重/香型/数量)，没扒到留白+备注需要什么动作才能扒到 |
| 定价漏盈亏平衡档 | 只给净利率表 | 定价必含"利润率0%"盈亏平衡售价档(商品卡/达人A/B三档) |
| 退货率等假设值未标来源 | 8%直接写死 | 假设值必须标"假设/未实测+来源"，并给运营自定售后率→模型出运营口径版的出口 |


## 待办/需用户输入项（每个产品都要问）

- 货源情况（供应商/补货周期/MOQ/库存/品牌归属）→ 补货稳定性打分
- 达人出单率/平均出单数 → 替换 A/B 假设
- 退货回程运费官方金额 → 替换暂估 2 万盾
- 卖家中心佣金预览/类目开放/收运 → 上架前确认
