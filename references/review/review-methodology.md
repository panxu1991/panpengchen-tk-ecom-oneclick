# TK 电商项目复盘与模型补强

> 由整场「车载香薰 SF BALM」对话蒸馏而成（女娲分析 + self-improving 复盘 + 仓颉蒸馏）。每次做完产品项目自动调用，避免重踩坑。

## 一、本轮复盘结论

做跨境 TK 电商产品，踩坑集中在五类：**图片真伪、计算口径、登录态、数据源、越南语**。补强后形成下面的标准流程。

## 二、双方优势与不足

### 模型（我）的优势
- 方法论蒸馏扎实：SOP、双体系盈亏、竞品时间维度、内容矩阵、变量复制。
- 确定性工具熟练：rembg 抠图、PIL 叠字、pdfplumber 提 CID PDF、openpyxl 建活表。
- 官方费率核验：用 pdfplumber 提取官方佣金 PDF 拿到精确类目档位。
- 快速纠错：样品成本、达人出单率、越南语拼写都在用户指出后立即修正。

### 模型（我）的不足（已修正）
1. 早期用 AI 凭空画产品（应抠真实图）。
2. 样品成本公式算错（(1-P)/P 应改为 1/P 全量摊销）。
3. 达人出单率中位数算错（70.26% 应 77.71%）。
4. 反复 kill 用户浏览器导致登录态失效。
5. 复制 profile 无法带过国内平台登录态。
6. batch delete+add 编辑同一文件失败（应用 replace_file）。
7. 让 AI 在图上渲染越南语（音调必错，应 PIL 叠字）。
8. 反复让用户配合（登录/调试端口），应一次性登录+同会话批处理。

### 用户（对方）的价值
- 精准指出问题（样品成本、达人出单率、越南语、主图 AI 感、详情图缺产品）。
- 提供关键信息（货源、品牌 SF BALM、样品含尾程、汇率）。
- 明确边界（放权、暂停、切换方向）。

### 协作摩擦点
- 调试端口命令多次未生效，应改用「双击 .bat 自动关开 Edge + 调试端口」的零手输方式。

## 三、模型补强方案（核心）

1. **图片**：真实产品图抠白（rembg）做底图；AI 只出「无字」场景/真人图；文字一律 PIL + Arial 程序化叠加。AI 出图不出字。
2. **计算**：所有公式带数值拆解；达人样品/出单率按 A/B 两档（中位数 vs 最低20%平均）；样品成本=产品+纸箱+边境仓+尾程全算。
3. **登录态**：不 kill 用户浏览器、不复制 profile；国内平台登录绑定浏览器实例，只能 CDP 直连运行中的浏览器，或用户手动导出。
4. **数据源**：市场/竞品用 FastMoss 游客榜优先；国内评论图受反爬限制，用「一次性登录+同会话批处理」；官方费率用 pdfplumber 提 PDF。
5. **自动化边界**：能全自动的（rembg/PIL/pdfplumber/openpyxl/脚本）全自动；需登录的一次性登录+批处理；无法自动的（扫码/滑块）明确告知并给「一键脚本」。
6. **越南语**：字符串先 underthesea 分词校验，再 PIL 叠字，音调零错误。
7. **编辑**：换整文件用 replace_file；删文件用 Python os.remove（shell 可能被策略拦）。
8. **完整性**：交付三层（可复用 SKILL / 产品完整分析 / 发布就绪终稿），不因「终稿精简」丢中间分析。

## 五、自循环机制

```text
用户反馈数据 → 漏斗定位(曝光→点击→加购→转化→退货) → 单变量优化 → 复盘 → 回写经验库和 references → 下次直接用新口径
```

每次复盘更新 `references/experience-library.md`，形成越用越聪明的经验库。

## 六、下次做产品的标准流程

1. 收产品链接 → 提取真实图 + 产品事实。
2. FastMoss 越南竞品（游客榜）+ 官方费率（pdfplumber）。
3. 产品成本优化：白底图 1688/义乌购以图搜款，对比成本写报告。
4. 选品打分表 + 双体系盈亏（全拆解+A/B）。
5. 真实图抠白 → AI 出无字底图 → PIL 叠越南语。
6. 标题公式 + 5 卖点 + 15 AI/5 真人脚本。
7. 全阶段 SOP（时间线+PLAN B/C）→ 打包终稿。
