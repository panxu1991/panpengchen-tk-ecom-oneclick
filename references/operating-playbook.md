# 0-100+ 工作流程总纲（出品流程 + 运营引擎，统一时间线）

> 本文件是**唯一阶段事实源**。SKILL.md 的「11 步流水线」和「运营引擎」都必须映射到本总纲，阶段/时间/进程/框架四处对齐，不允许错位。

## 一、整体模型（消除错位）

- **出品流程（11 步）** = 0-1 的「上架交付」子流程，**D1-D6 一次性**，产品 → 交付包。
- **工作流程（5 阶段）** = 0-1 → 1-10 → 10-99 → 99-100 → 100+，**持续**。
- **时间轴**：D1-D14 = 0-1；第 3-6 周 = 1-10；第 2-4 月 = 10-99；第 4-5 月 = 99-100；第 6 月+ = 100+。
- **运营引擎**（测款/达人/流量/投流/内容迭代/履约复盘）不是独立阶段，而是**贯穿 1-10 到 100+ 的引擎**，落到各阶段动作里。

## 三、工作流程（五阶段）

### 阶段 0-1：上架交付 + 出首单（D1-D14）

- **目标**：跑通出品流程，上架，出首单，验证链路。
- **时间**：第 1-2 周（D1-D6 出品流程；D6-D14 上架 + 首单）。
- **动作**：
  1. 确认主体/资质 + 跨境 POP 入驻 + 税码/保证金（D1-D3，可与出品流程并行）。
  2. 履约配置：京东边境仓入库地址 + 越南尾程模板 + 退货地址（D3-D5）。
  3. 执行出品流程 11 步，产出交付包（D1-D6）。
  4. 上架（用交付包素材），过 `listing_qa.py`（D6-D7）。
  5. 出首单，走通边境仓 + 平台尾程全链路（D7-D14）。
- **框架落点**：Listing SEO/CRO + 9 图（上架）、落地成本 + 竞品价格地图（定价）、评论分析（选品）。
- **产出**：交付包、店铺校验记录、税码/保证金状态、履约配置、上架 QA、首单记录。
- **KPI/门禁**：首单 + 商品卡 CTR≥1%；贡献利润在保守费率和退货假设下为正。发布是不可逆动作，需授权。
- **PLAN B**：首单难 → 换主图/降价 42k 测价格弹性；**PLAN C** → 换品或换履约（本土仓按件计费）。

### 阶段 1-10：稳定出单（第 3-6 周）

- **目标**：从个位数 SKU 扩到 30-50 个，建立可重复的测款/内容/补货/售后节奏。
- **时间**：第 3-6 周（4 周）。
- **动作**：
  1. 测款窗（14 天三线）：升级日均≥3单→加量备货；维持→继续；止损 14天<8单→淘汰；CTR<1%→先换主图/标题再谈淘汰。
  2. 内容迭代：爆款追踪表周更；爆款出 3 变体（开头/场景/口播）；14天播放<500不追投；AI铺量测钩子、真人验证转化。（nexscope：内容策略）
  3. 达人小样先行：先 10 人校准建联转化率，再扩 50；出单 ROI≥1 续投、<1 停。（nexscope：联盟计划）
  4. 流量组合：自然跑 2 周验证素材 → 上 GMV Max（5%交易费档）7 天观测；直接 ROAS≥1.2 续投、综合 ROAS≥1.5 才放大。（nexscope：广告架构）
  5. 批量上新：每周固定批次（5-10 个），每个过选品打分 + 单位经济。
  6. 补货线：安全库存 = 日均单 × 补货周期 × 1.5；差评三级 SOP（功能/物流/描述不符）。
  7. 周复盘：漏斗 + 渠道 + 环比 → 定位异常 → 单变量优化。（nexscope：数据分析）
- **产出**：30 天内容日历、达人管线表、投流追踪表、选品批次表、补货 SOP、差评 SOP、周店健康报告。
- **KPI/门禁**：日均 5-10 单、达人出单率≥50%、退货率<8%；只有扣完所有费用仍盈利的角度才放量。
- **PLAN B**：达人若不划算→主攻商品卡+投流；**PLAN C**：升级 4/6 盒装摊薄固定费，客单上探 78k-108k。

### 阶段 10-99：放大利润（第 2-4 月）

- **目标**：把头部 SKU 做成稳定组合，边际从 13% 拉到 25%+。
- **时间**：第 2-4 月（3 个月）。
- **动作**：
  1. SKU 分层：scale/repair/harvest/exit，重配库存/内容/达人/广告。
  2. 达人矩阵 50+ 铺量，佣金 12% 内，样品按 B 档备货。（nexscope：联盟计划-分层佣金）
  3. 投流放大：10→20→50 美金，每级连续 7 天综合 ROAS≥1.5 才翻倍，跌破 1.2 回退；只放盈利素材。（nexscope：广告投放）
  4. 多盒装：主推 4/6 盒装，摊薄边境仓固定费 + 订单处理。
  5. 供应链：1688/义乌购图搜同款压成本；补货周期/滞销/回款/汇率风控。
  6. 履约切换评估：边境仓 vs 越南本土仓/平台仓（费率/时效/压货/现金流/退货）。（nexscope：履约模型对比）
  7. 月复盘：CAC/LTV/AOV/贡献利润诊断，找 #1 增长杠杆。（nexscope：增长诊断）
- **产出**：SKU 组合评审、滚动 30/60/90 天计划、履约切换备忘录、投流/达人追踪表。
- **KPI/门禁**：日均 30-50 单、净利率≥20%、综合 ROAS≥1.5、保本 ROI≥3；扩张须保现金缓冲 + 店铺健康。
- **PLAN B**：砍达人改纯商品卡+投流省 12% 佣金；**PLAN C**：切越南本土仓按件计费重算。

### 阶段 99-100：冲刺爆品（第 4-5 月）

- **目标**：集中资源把 1 个头部 SKU 打爆。
- **时间**：第 4-5 月（2 个月）。
- **动作**：
  1. 头部 SKU：聚焦销量第一的规格/颜色，集中补货 + 投流。
  2. 直播：达人直播 + 店播，主推 4 盒装高客单。（nexscope：数据分析-直播层）
  3. 大促：报名活动、满减/赠品，冲 GMV 排名。（nexscope：促销）
- **KPI/门禁**：单日 100 单、单 SKU 总销量破万、直播 GMV/场持续为正。
- **PLAN B**：收缩投流保利润转防御型；**PLAN C**：换季换品（种植盲盒有春秋旺季）。

### 阶段 100+：复制扩张（第 6 月+）

- **目标**：把跑通的单品复制到多品类/店群/跨市场。
- **时间**：第 6 月+（持续）。
- **动作**：
  1. 品类复制：同法复制到「儿童手作/科学实验/收纳」等高内容百货。
  2. 供应链升级：越南本土仓 + 按件计费，摆脱重量计费约束。
  3. 店群：复制成功单品到 2-3 个店。
  4. 品牌层：品牌人格 + 内容支柱 + 社区运营（nexscope：品牌建设）。
  5. 跨市场：用 8 维评分给泰国/马来等打分，决定是否扩（nexscope：跨境市场评分）。
- **KPI/门禁**：3+ 跑通单品、单店月 GMV 稳定、跨市场评分前 2-3 才扩。
- **PLAN B**：聚焦单一店不做店群；**PLAN C**：暂缓跨市场，深耕越南。
