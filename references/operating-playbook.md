# 0-1 / 1-10 / 10-100 分阶段操作手册

> 上架后的持续出单引擎（测款/达人/投流/内容迭代/复盘）见同目录 `growth-engine.md`；三张追踪表用 `scripts/growth_tables.py` 生成。


按阶段门禁推进，产出未完成不进入下一阶段。品类或政策快照变化时重算单位经济。百货店的核心纪律：**宽 SKU 靠淘汰，不靠押注**——用低成本测款快速筛出能盈利的 SKU，淘汰不达标的，再对头部集中资源。

## 0-1：把店开起来并出首单

目标：在不多花钱的前提下，确认合规、履约链路和第一批 SKU 能跑通。

动作：
1. 确认主体和资质：大陆/香港企业或个体工商户，法代证件、手机号/邮箱唯一性、可选第三方店铺经验截图。
2. 跨境 POP 入驻，走东南亚注册入口，选越南市场，等待审核（常见约 3 个工作日，以官方口径为准）。
3. 卖家中心基础配置：店铺名/Logo/横幅、税码提交与核验、结算账号、保证金或豁免决定。
4. 履约配置：确定京东边境仓入库地址、平台越南尾程的配送模板、仓库/退货地址、客服时间、订单处理规则。先不批量铺货，先跑通链路。
5. 首批选 5-10 个百货 SKU（家居日用/厨房/收纳/清洁优先），按 `selection-and-sourcing.md` 打分，只用合规且保守贡献利润为正的 SKU。
6. 每个 SKU 跑单位经济，把当前费率/税作为显式输入，过贡献利润 gate。
7. 上架前跑 `listing_qa.py`，确认类目、属性、税费敏感价、图片、库存、配送、退货都过检。
8. 发布首批 SKU，出首单并走通边境仓 + 平台尾程全链路。

产出：店铺校验记录、税码状态、保证金/豁免记录、履约配置清单、首批 SKU 选品表、`unit_economics.json`、上架 QA 记录。

门禁：贡献利润在保守费率和退货假设下为正、品类合规、履约链路确认，才允许发布可售 SKU。发布是不可逆外部动作，需授权。

## 1-10：稳定出单并跑通批量上新

目标：从个位数 SKU 扩到 30-50 个，建立可重复的测款、内容、补货、售后节奏。

动作：
1. 内容冷启动：按 `content-and-traffic.md` 建内容矩阵，短视频 + 达人 + 小额广告测试，先找能稳定产出盈利订单的角度。
2. 批量上新节奏：每周固定批次上新（例如每周 5-10 个），每个 SKU 都过选品打分和单位经济，杜绝「拍脑袋铺货」。
3. 边境仓补货 SOP：确定最小起订/补货点、到边境仓的入仓时效、清关与贴单交接，异常件上报。
4. 售后管控：延迟发货、跟踪、妥投 SLA、取消、退货、退款、纠纷的异常日志和越南语客服话术库。
5. 周复盘：按 SKU 对账费用、税费、退款、广告、达人费、COGS、物流，找出和模型的偏差。
6. 测款窗（14 天）：每个 SKU 设三线（升级日均≥3单/维持/止损<8单），CTR<1% 先换素材再谈淘汰。
7. 达人小样先行：先 10 人校准建联转化率，再扩 50；出单 ROI≥1 续投、<1 停。
8. 内容迭代：爆款追踪表周更，爆款出 3 变体，14 天播放<500 不追投。


产出：30 天内容日历、达人管线、测试预算、每周选品批次表、补货 SOP、异常日志、周店健康报告、退款原因分类。

门禁：只有「扣完费用、广告、达人费、退货后仍盈利」的角度才放量；服务指标或贡献利润跌破阈值就停该 SKU。

## 10-100：放量、供应链风控与切换评估

目标：把头部 SKU 做成稳定组合，并在规模上来后评估履约升级。

动作：
1. SKU 分层：scale / repair / harvest / exit，重配库存、内容、达人、广告。
2. 放量：达人矩阵、直播、GMV Max，只放大已证明盈利的角度。
3. 供应链与资金链风控：补货周期、滞销库存、回款周期、汇率换算用记录的时间戳口径，不要混币。
4. 履约切换评估：对比「京东边境仓 + 平台尾程」和「越南本土仓/平台仓」的费率、时效、压货、现金流、退货，形成切换备忘录。
5. 投流放大：自然跑通后上 GMV Max（5%交易费档），直接 ROAS≥1.2 续投、综合 ROAS≥1.5 才放大预算，10→20→50 美金每级稳定 7 天。

5. 跨类目扩展前先查保证金、关税、佣金、合规、履约影响，再决定。

产出：SKU 组合评审、滚动 30/60/90 天计划、履约切换备忘录、自动化 runbook、季度扩/退决策。

门禁：扩张必须保住现金缓冲、店铺健康、合规和目标贡献利润。

## 通用纪律

- 事实分层标注来源日期和置信度；官方冲突时不擅自选值。
- 不可逆动作（发布、改价、付保证金、改税号、账户变更）先授权后执行。
- 图片只写盘不入对话，`refs/` 不读取。
- 每周政策巡检，更新快照和变更日志。
