# 单位经济（POP + 京东边境仓 + 平台尾程）

## 输入

费率、税率、费用都作为显式输入，不要硬编码。核心输入：

- 售价、卖家优惠、平台补贴、买家付尾程运费（`customer_shipping_paid`）。
- 佣金率（类目专属，非 Mall 默认 14%）、交易费率 6%、订单处理费 3000 VND、所得税率 1%。
- 达人费率、广告单均成本、退货准备金。
- COGS（采购 + 国内到边境仓运费 + 包装）、京东边境仓费。
- 包装耗材/纸箱（`packaging_cost`）：按产品配送条件分级——布类/抹布=0（不用纸箱），普通耐用小件=0.3-0.6 元，易碎/膏体/液体容器=0.6-1.5 元（需要保护性纸箱/气泡袋）。纸箱按规格计价，多瓶装选更大规格时成本上浮。
- 进口 VAT、高价值关税：默认 0，除非确认平台代扣再显式设 `vat_base`/`tariff`。

## 计算（2026-10-08 修正口径）

```text
商品实付 = 售价 - 卖家优惠
卖家实际收款 = 商品实付 + 平台补贴          # 不含买家付的尾程运费
佣金 = 佣金率 × (商品实付 + 平台补贴)
交易费 = 6% × (商品实付 + 平台补贴 + 买家付尾程运费)   # 基数含尾程运费
所得税 = 1% × (商品实付 + 平台补贴)         # 跨境企业所得税代扣
订单处理费 = 3000 VND/妥投单
平台费用 = 佣金 + 交易费 + 订单处理费 + 所得税
变动成本 = 达人费 + COGS + 边境仓费 + 广告费 + 退货准备金 + 其他成本
包装纸箱（若需）：香膏/易碎品额外计入 packaging_cost，抹布等布类为 0
贡献利润 = 卖家实际收款 - 平台费用 - 变动成本 - 税费影响(VAT/关税)
```

关键口径：**尾程运费由买家付，不是卖家成本**（`last_mile_fee=0`），但它仍计入 6% 交易费的基数。边境仓模式下平台默认不代扣进口 VAT（`vat_base=0`）；若你确认某链路平台代扣，再显式设 `vat_base`。

## 门禁

- 保守费率和退货假设下贡献利润 > 0 才推进 SKU。
- 盈亏平衡价用脚本输出，作为谈判和定价下限参考。
- 最终定价用类目 PDF 和卖家中心费用预览按具体 SKU 算。

## 脚本用法

```bash
python scripts/unit_economics.py --example
python scripts/unit_economics.py --input unit_economics.json
```

JSON 输入覆盖脚本 DEFAULTS 中任一字段，未提供字段用默认值。费率用小数（14% 写 0.14）。
