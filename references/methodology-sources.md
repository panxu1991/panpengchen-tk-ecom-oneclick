# 权威方法论来源笔记

本文件记录专家视角 skill 所综合的方法论来源和核心论点。内容为框架性综合，不冒充官方数据。

调研时间：2026-10-07（Asia/Shanghai）。来源类型：二手方法论文献（用于提炼经营框架，不作费率/税/合规的最终依据）。

## 核心论点来源

### 选品与淘汰

- 百货宽 SKU 的经营核心是「低成本测款 + 快速淘汰」，而不是押注单品。
- 选品先看越南真实需求信号、竞品差评、内容可拍性、退货/合规风险，再看毛利。

### 单位经济

- 每 SKU 必须用「贡献利润 = 买家实付 - 平台费用 - 达人/广告 - COGS - 物流 - 退货 - 税」做 gate，不用 GMV 或订单量替代利润。
- 盈亏平衡价是定价和采购谈判的下限。

### 履约与供应链

- 跨境履约的时效、退货、清关、状态回传直接影响店铺健康和资金链，是产品体验的一部分。
- 补货周期、滞销库存、回款周期决定现金缓冲，压货前先算现金流。

### 内容与流量

- 内容矩阵围绕「场景/问题/演示/对比/证明」做可重复内容，而非赌单条爆款。
- 达人/广告只对已验证盈利的角度放量，追踪到贡献利润。
